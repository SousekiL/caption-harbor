# Bundled fonts

Unmodified variable TTF fonts downloaded from the Google Fonts distribution, 2026-09-20. CSS aliases distinguish these packaged files from system-installed copies.

- [Roboto Slab](https://github.com/google/fonts/tree/main/apache/robotoslab), Christian Robertson / The Roboto Slab Project Authors. Apache License 2.0; see RobotoSlab-LICENSE.txt.
- [Lexend](https://github.com/google/fonts/tree/main/ofl/lexend), The Lexend Project Authors. SIL Open Font License 1.1; see Lexend-OFL.txt.

Source filenames are RobotoSlab[wght].ttf and Lexend[wght].ttf. Binary contents are unmodified. The extension loads these files locally and does not contact Google Fonts at runtime. Chinese characters fall back to system fonts.
